# Archived remake recordings

Former Unity phoneme recordings, retained with original import metadata for
A/B comparisons and waveform analysis. Runtime speech now uses the original
engine and bank; these files are outside Unity's Assets tree.

Noise, birdsong and pop are actual effects and remain in
`Assets/Sounds/Phoneme_v2/`. See `docs/SPEECH_ENGINE.md` for the current path and
extended-vowel/bank-selection findings. Historical metadata is evidence, not
an instruction to reimport these as runtime speech.
